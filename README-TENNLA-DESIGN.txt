ТЕННЛА / MYTHRAS TOOLS — ВИЗУАЛЬНАЯ ИТЕРАЦИЯ V2
================================================

Этот пакет содержит ТОЛЬКО изменения дизайна итогового листа.
Не меняются TypeScript-сервисы, правила Mythras, модели персонажей,
сохранения, броски и игровая логика.

Что изменено
-------------
• Композиция шапки: более крупный знак кампании, светлый архитектурный фон,
  небольшая гравировка солнца/колонн и более выразительная типографика.
• Навыки: тёмно-морская боковая панель с золотистыми процентами и
  вертикальными группами; сохранены поиск и нажатия на навыки.
• Персонаж: портрет в арочной рамке, отдельная строка-лейбл, контрастная
  полоса семи характеристик в морской гамме.
• Ресурсы: светлая каменная подложка, более читаемые значения и разделители.
• HP: аккуратная светлая схема тела с характерными маркерами и статусами.
• Оружие/броня: спокойный "редакционный" раздел с ясными заголовками.
• Состояния: отдельное оформление, отличное от ресурсов.
• Окна проверки/экипировки: единые отступы, заголовки и фокусные состояния.
• Адаптивная компоновка для широких и узких экранов.

Как применить (вариант А — Git patch, рекомендуется)
----------------------------------------------------
1. Сделайте отдельную ветку и сохраните текущие изменения в Git.
2. Скопируйте tennla-design.patch в удобную папку.
3. Откройте PowerShell в корне вашего mythras-tools.
4. Проверьте патч:
     git apply --check "ПУТЬ_К_ФАЙЛУ/tennla-design.patch"
5. Если ошибок нет, примените:
     git apply "ПУТЬ_К_ФАЙЛУ/tennla-design.patch"
6. Запустите:
     npm start
7. Откройте http://localhost:4200/#/view

Как применить (вариант Б — ZIP)
-------------------------------
Раскройте ZIP непосредственно в корень существующего проекта mythras-tools,
разрешив замену четырёх существующих файлов. Пятый SCSS-файл добавится.
В PowerShell пример:
     Expand-Archive -Path "ПУТЬ_К_ФАЙЛУ/tennla-design-files.zip" -DestinationPath . -Force

ПРИМЕЧАНИЕ: применяйте ЛИБО .patch, ЛИБО .zip, не оба сразу.
Оба варианта содержат одни и те же изменения.
